Gold.Brain.EA — Android PWA project
Founder: Thomas Wilhelm

This is an installable-web-app project, not a compiled APK.
To install from Android: host all files on a trusted HTTPS static host, open the HTTPS address in Chrome, then use the menu and choose Install app or Add to Home screen.

Opening index.html directly from Downloads previews the interface but does not enable PWA installation.
The prototype has no live prices, verified signal engine, HFM connection, or order execution. Never enter broker credentials.
